Liefwork

Liefwork is software that I developed that renders a folder tree as a “coral”: folders become branches, files become liefs, and the whole structure is visible at once.

This open structure lends itself to the Liefwork Memory System, a way of working with AI agents that distills context in a way that is simple, efficient and readable by humans and agents alike.

The Liefwork for Obsidian plugin was published in the community directory in July 2026.

For more visit liefwork.com.
